## 🌿 About This Policy

Security is an important part of this project.

This repository may contain **applications, APK files, releases, source code, scripts, documentation, and other software-related resources**.

This policy explains how to report security vulnerabilities and how security-related issues should be handled.

> 🔐 **If you discover a serious security issue, please report it privately instead of publicly exposing it.**

## 🚨 Reporting a Vulnerability

If you discover a potential security vulnerability affecting this repository, its releases, files, scripts, or related infrastructure, please report it **privately**.

### 📋 Please Include

When submitting a report, provide as much useful information as possible:

* 🧩 **Affected application or file**
* 🏷️ **Affected version / release**
* 📝 **Clear description of the vulnerability**
* 🔁 **Steps to reproduce the issue**
* 💥 **Potential security impact**
* 📸 **Screenshots, logs, or proof-of-concept information**
* 🛠️ **Possible mitigation or suggested fix**

> ⚠️ **Never include passwords, private keys, API tokens, personal information, or other sensitive credentials in a report.**

---

## 🔎 What Should Be Reported?

Please report issues such as:

* 🦠 Malicious or suspicious code
* 📡 Unexpected network communication
* 🔑 Exposed API keys, passwords, or authentication tokens
* 📦 Compromised or tampered release files
* 🧬 Supply-chain or dependency vulnerabilities
* ⚙️ Security weaknesses in scripts or build processes
* 🚪 Unauthorized access
* 🕵️ Unexpected collection or transmission of sensitive information
* 💣 Malware or potentially harmful content

When in doubt, **report the issue privately** so it can be reviewed.

---

## 📱 APK & Application Security

Applications and APK files should always be handled carefully.

Before installing an APK or other binary release, users are encouraged to:

* ✅ Download it from the intended repository release.
* 🔍 Verify the version and release information.
* 🔐 Review requested application permissions.
* 🛡️ Use appropriate security or antivirus tools.
* 🚫 Avoid unknown mirrors and untrusted download sources.
* 💾 Keep important data backed up.
* 🔄 Prefer newer releases when available.

> ⚠️ **No software can be guaranteed to be completely free of vulnerabilities.**

---

## 🧪 Modified & Third-Party Applications

Some applications distributed through this repository may originate from third parties or may have been modified for research, testing, experimentation, or other permitted purposes.

For such software:

* 🏢 The original developer remains responsible for upstream security.
* 🔧 Modified builds may differ from the original application.
* ⚠️ Security characteristics may change after modification or repackaging.
* 📜 Third-party applications remain subject to their respective licenses and terms.
* 🌐 Upstream vulnerabilities should also be reported to the original developer when appropriate.

> 💡 **Always evaluate software before installing or using it on a device containing sensitive information.**

## 🔑 Credentials & Sensitive Information

Please **never commit sensitive information** to this repository.

Examples include:

```text
🔐 Passwords
🔑 API Keys
🎟️ Authentication Tokens
🗝️ Private Keys
✍️ Signing Keys
👤 Personal Access Tokens
🗄️ Database Credentials
⚙️ Private Configuration Files
```

If sensitive information is accidentally exposed, report it privately as soon as possible.

## 🤝 Responsible Disclosure

We strongly encourage **responsible disclosure**.

Please allow reasonable time for a reported vulnerability to be:

1. 🔍 Investigated
2. 🧪 Reproduced
3. 📊 Assessed
4. 🛠️ Remediated where appropriate
5. 📢 Communicated when necessary

Please avoid publicly publishing exploitable details before the issue has been reviewed.
